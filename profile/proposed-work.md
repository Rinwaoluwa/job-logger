# Proposed work

Plausible work for each role that is NOT recorded as done. It lets a résumé
reach for concrete, company-fitting material when a posting asks for
something the verified profile lacks.

Rules for this file (the parser and prompts enforce what they can):
- It feeds ONLY the résumé gap-fill planner. It never reaches stories,
  cover letters, application answers or interview prep, and nothing here is
  a fact about what happened.
- A résumé that uses an entry carries it as a labelled "Gap fill:" item that
  is on the page unless you reject it; the entry's estimate is the one
  simple figure that fill may carry.
- Each entry stays inside its role's real product, users and era.
- An interviewer can probe any of these. Delete an entry you are not
  willing to defend. This whole file is optional: delete every entry if you
  do not want invented material offered at all.

Fields: Role, Area, Use case, Tools, How, Impact, Estimate, Keywords, Be ready
to explain. Ids are `pw-<role>-N`.
